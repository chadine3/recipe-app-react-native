# Recipe App - React Native

Application mobile développée avec React Native permettant de consulter des recettes à partir de l'API TheMealDB.

## Fonctionnalités

- Affichage des catégories de recettes
- Filtrage des recettes par catégorie
- Recherche de recettes par nom
- Affichage des détails d'une recette
- Navigation entre plusieurs écrans
- Consommation d'API REST

## Technologies utilisées

- React Native
- Expo
- React Navigation
- JavaScript
- TheMealDB API
